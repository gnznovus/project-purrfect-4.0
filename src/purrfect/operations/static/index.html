ENGINEERING CONSTRAINTS

Known reliability boundaries

NOT GUARANTEED
01
Redis failover consistency

Single-primary lease fencing is implemented; asynchronous failover behavior still needs fault-injection validation.

02
Remote inference cancellation

A canceled lease stops local acceptance but cannot guarantee termination inside an external model runtime.

03
Globally fair queue ordering

The global Redis gate caps concurrency. Strict fairness between workers is not yet implemented.

04
Multi-worker metrics aggregation

Gateway histograms are process-local. The Console currently observes one configured Gateway endpoint.
